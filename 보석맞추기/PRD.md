# 보석 맞추기 — 제품 요구사항 문서 (PRD)

- 작성일: 2026-11-07
- 상태: 배포됨 (GitHub Pages)
- 저장소: https://github.com/wooryihwang/claude-code (`보석맞추기/` 폴더)
- 플레이 주소: https://wooryihwang.github.io/claude-code/보석맞추기/

## 1. 개요

8×8 판에서 같은 보석을 맞춰 없애는 퍼즐 게임입니다. 설치 없이 브라우저에서 `index.html` 한 파일로 돌아갑니다. 한 판은 이동 20번으로 끝나서 몇 분 안에 마칠 수 있습니다.

## 2. 목표

| 목표 | 기준 |
|---|---|
| 바로 할 수 있는 게임 | 주소만 열면 로그인·설치 없이 시작 |
| 짧은 한 판 | 이동 20번, 한 판 3~5분 |
| PC와 휴대폰 모두 지원 | 마우스 끌기, 터치, 키보드로 조작 |
| 다시 하고 싶게 만들기 | 연쇄 배수, 최고 점수, 내 기록 |

### 하지 않는 것 (현재 범위 밖)
- 로그인, 사용자 계정
- 여러 사람이 함께 보는 점수판 (기록은 각자의 브라우저에만 저장)
- 특수 보석(폭탄, 줄 지우기 등), 스테이지·목표가 있는 레벨
- 소리, 배경음악

## 3. 사용자

- 수업 쉬는 시간이나 활동 보상으로 게임을 하는 학생
- 학생에게 주소를 나눠 주는 교사

## 4. 게임 규칙

### 4.1 판
- 8×8 칸, 보석 6종이 무작위로 놓입니다.
- 처음 판에는 이미 맞춰진 줄이나 2×2 네모가 없고, 맞출 수 있는 수가 하나 이상 있습니다.

### 4.2 보석

| 번호 | 이름 | 색 | 모양 |
|---|---|---|---|
| 0 | 루비 | 빨강 | 마름모 |
| 1 | 토파즈 | 노랑 | 육각형 |
| 2 | 에메랄드 | 초록 | 삼각형 |
| 3 | 자수정 | 보라 | 팔각형 |
| 4 | 사파이어 | 파랑 | 브릴리언트 컷 |
| 5 | 투르말린 | 분홍 | 십각형 |

보석 그림은 모두 코드(SVG)로 직접 그립니다. 외부 이미지 파일이 없습니다.

### 4.3 이동
- 맞닿은(상하좌우) 두 보석의 자리를 바꿉니다.
- 바꾼 결과로 깨지는 보석이 없으면 원래 자리로 돌아가고, 이동 횟수는 줄지 않습니다.
- 깨지는 보석이 있을 때만 남은 이동이 1 줄어듭니다.

### 4.4 깨지는 조건과 점수

| 모양 | 점수 |
|---|---|
| 한 줄(가로·세로)로 같은 보석 3개 | 60 |
| 한 줄로 4개 | 120 |
| 한 줄로 5개 이상 | 200 |
| 같은 보석 4개가 2×2 네모 | 100 |

- 한 번에 여러 모양이 생기면 모양마다 점수를 더합니다. 겹치는 칸이 있어도 각 모양을 따로 셉니다.
- 깨진 자리는 위 보석이 내려와 채우고, 빈칸에는 새 보석이 위에서 떨어집니다.
- 떨어진 뒤 또 맞춰지면 연쇄입니다. 연쇄 단계마다 점수에 배수를 곱합니다(첫 번째 ×1, 두 번째 ×2, 세 번째 ×3 …).

### 4.5 판 섞기
- 맞출 수 있는 수가 하나도 없으면 "섞는 중"을 보여 주고 새 판으로 바꿉니다. 점수와 남은 이동은 그대로입니다.

### 4.6 게임 끝
- 남은 이동이 0이 되고 연쇄가 모두 끝나면 게임이 끝납니다.
- 끝 화면에 최종 점수, 모은 보석 수, 가장 많이 모은 보석을 보여 줍니다. 최고 점수를 넘으면 "새 최고 기록입니다!"를 보여 줍니다.

## 5. 화면 구성

위에서 아래로:
1. 제목 "보석 맞추기"와 한 줄 설명
2. 점수판 3칸: 점수, 남은 이동(5 이하이면 붉은색), 내 최고 점수
3. 8×8 보석 판 (벨벳 판에 금색 테두리)
4. 모은 보석: 6종별로 깬 개수
5. 버튼: 힌트, 내 기록, 새 게임
6. 조작법과 점수 규칙 안내

### 효과
- 고른 보석: 테두리와 커지는 움직임
- 깨질 때: 반짝이며 사라짐, 얻은 점수가 떠오름 (`+120`)
- 연쇄일 때: "연쇄 ×2" 표시
- 힌트: 바꿀 수 있는 두 보석이 2.2초 동안 흔들림
- 움직임 줄이기 설정(prefers-reduced-motion)을 켠 사용자에게는 애니메이션을 짧게 합니다.

## 6. 조작

| 방법 | 동작 |
|---|---|
| 끌기 (마우스·터치) | 보석을 누른 채 옆 칸 방향으로 끌면 자리 바꾸기 |
| 두 번 누르기 | 보석 하나를 누르고 옆 보석을 누르면 자리 바꾸기. 같은 보석을 다시 누르면 선택 취소 |
| 키보드 | 판을 선택한 뒤 화살표로 칸 이동, Enter·Space로 고르기, Esc로 취소 |

## 7. 기록 저장

- 게임이 끝날 때마다 점수와 날짜를 브라우저 localStorage(`jewel-records`)에 저장합니다.
- 높은 점수순으로 최대 10개까지 남기고, "내 기록"에서 보여 줍니다.
- 저장이 막힌 브라우저(시크릿 창 등)에서도 게임은 정상으로 돌아가고, 기록만 남지 않습니다.

## 8. 기술 사항

- 파일: `index.html` 한 개 (HTML, CSS, JavaScript 모두 포함), 외부 라이브러리 없음
- 글꼴: Google Fonts의 Do Hyeon(제목·숫자), Gowun Dodum(본문). 불러오지 못하면 시스템 글꼴 사용
- 보석 위치: 칸마다 CSS 변수(`--r`, `--c`)로 정하고 transform 전환으로 미끄러지듯 움직임
- 화면 폭: 휴대폰(약 400px)부터 PC까지, 판은 최대 540px 폭의 정사각형
